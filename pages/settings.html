              System Diagnostics

              Run a quick system check to detect missing files, offline problems, storage issues, and other common problems in the system.

              💾 Device Storage

              This device can keep about 5 MB. Patient records live in the shared cloud database (Supabase) — only drafts, settings and your sign-in are stored here. Draft photos use most of the space.

              Checking…

              The clean-up button removes only old draft photos. No draft, no report and no saved patient record is deleted, and the shared database is not touched. To check the numbers yourself, open DevTools (F12) → Console and type EntStorage.logToConsole().
