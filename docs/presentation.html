ENT Endoscopy System

Clinical Documentation, Reporting & Offline-Ready Platform for ENT Specialists

Presented to: Medical Staff / Doctors  |  Platform: Web-based PWA  |  Backend: Supabase (PostgreSQL + Edge Functions)

1. System Purpose

  • Centralized digital record of ENT endoscopy procedures (nasal & laryngeal) and CF4 forms.
  • Replaces paper-based reporting with structured, searchable, auditable digital records.
  • Supports multi-clinic, multi-doctor workflows with secretary/admin assistance.
  • Works online and offline — doctors can document during travel/field work.
  • Generates print/PDF-ready reports with embedded procedure images.

Security: Row-Level Security (RLS) in PostgreSQL, JWT-based sessions, Edge Functions for privileged ops, CORS origin allowlist.

4. Data & Security Architecture

  • Database: Supabase PostgreSQL with 41+ numbered migrations, RLS policies, audit triggers.
  • Auth: Supabase Auth + custom auth-admin Edge Function (sole account lifecycle manager).
  • Storage: Patient photos via patient-photos Edge Function (RLS-gated).
  • Offline Grant: PBKDF2-SHA256 (210k iterations), 180-day validity, no password stored.
  • Privacy: No service-role key in frontend; cross-clinic grants audited; soft-delete recycle bin.

5. Offline Mode (Doctor-Only)

  • PWA with Service Worker precaching app shell + 3 report modules.
  • Offline login via local grant (username + password), 12-hour tab session.
  • Drafts & photos saved in IndexedDB; survive logout/restart.
  • Pending-report queue syncs automatically when connectivity returns.
  • Conflict detection: remote edits never overwritten; surfaced as "Sync Failed".
  • Photos remain local-only until online upload (clearly labeled).

Verified: All 16 offline-queue regression checks PASS.

6. Clinical Workflow

  1. Doctor logs in (online or offline grant).
  2. Selects patient / creates new record.
  3. Fills structured endoscopy form + attaches photos.
  4. Saves draft (auto-save) or finalizes report.
  5. Prints / exports PDF with images.
  6. Offline: queued for sync; online: stored in Supabase immediately.
  7. Admin/secretary can view granted records; audit trail retained.

7. Reporting & Print/PDF

  • Tight A4 layout: text fills page, images arranged in square grid (0/2/3 images).
  • Print preview support (printReport({showPreview:true})).
  • CF4 forms follow WAFO format (reference PDFs included).
  • Images embedded base64 for offline-capable printing.

8. Quality Assurance & Testing

  • Automated regression suites: offline queue, draft identity, duplicate guard, photo invariants, photo validation, drafts team.
  • Migration validation, grant/function grant checks, frontend contract tests.
  • Deployment verification includes CORS preflight checks (catches browser-only failures).
  • Offline-ready verification ensures all cached files present before travel.

9. Deployment & Operations

  • Hosted on GitHub Pages (HTTPS PWA) or any static host.
  • Backend on Supabase (database + edge functions).
  • Environment: ENT_ALLOWED_ORIGIN, ENT_SUPABASE_URL, ENT_SUPABASE_ANON_KEY.
  • Pre-publish scan prevents service-role key leakage.
  • No migration/RLS changes needed for offline scope.

Form A — Nasal Endoscopy

  • Patient demographics & visit info (name, age, sex, date).
  • Nasal cavity findings: septum, turbinates, mucosa, discharge, polyps.
  • Endoscopic findings per side (left/right), obstruction, crusting, bleeding.
  • Impression / diagnosis & recommended management.
  • Photo attachments (base64) + print/PDF export.

Form B — Laryngeal Endoscopy

  • Patient demographics & clinical history.
  • Laryngeal structures: epiglottis, arytenoids, vocal cords, glottis, subglottis.
  • Mobility assessment, lesions, edema, reflux signs.
  • Diagnosis & management plan.
  • Photo attachments + print/PDF export.

Form C — CF4 (Claim Form)

  • I. HCI information (name, accreditation, address).
  • II. Patient data (name, PIN, age, sex, complaints, diagnoses, admission/discharge).
  • III. Reason for admission (history, symptoms, referrals).
  • IV–VII. Physical exam (vitals, HEENT, chest, CVS, abdomen, GU, skin, neuro).
  • VIII–X. Course in ward, procedures, medications, discharge plan.
  • Generates WAFO-format output (reference PDFs included).
